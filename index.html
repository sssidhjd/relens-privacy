隐私政策

更新日期：2026 年 9 月 1 日 · 适用版本：2.1.3

一句话说明

ReLens 只在你主动选择图片并确认后分析或生成；不会持续扫描网页、读取浏览历史或出售用户数据。当托管服务已启用、可用且由你主动使用时，完成任务所需的数据会发送给 ReLens 后端和下方列出的模型服务商。

本机历史

可以关闭、导出或清空，不保存原图；最近 30 条记录可带低清缩略图。

托管结果

分析文本最长保留 30 天，生图结果链接最长约 48 小时，用于找回结果和结算。

由你发起

分析或生图需要发送图片与文字。关闭本机历史不会停止已由你发起的云端处理。

以上是便于阅读的摘要。完整的数据处理范围、保留规则和第三方说明，请查看下方条款。

1. 单一用途

ReLens 用于把用户主动选择的一张网页图片、网页框选区域或本地图片转换为详细的中文提示词、英文提示词、负面提示词和结构化 JSON，并允许用户主动继续生成一张图片。扩展不会持续扫描网页、读取浏览历史或出售用户数据。

2. 两种使用方式

ReLens 托管模式（服务启用时）：用户使用邮箱账户和积分，不需要填写模型 API Key。发布者启用且服务可用时，扩展把完成分析或生成所需的数据发送至 ReLens 后端，再由后端调用平台模型。

使用自己的 API（高级）：用户自行选择并授权 Google Gemini、OpenAI、Anthropic Claude、阿里云百炼或 OpenAI-compatible 服务。请求直接发送至相应接口，费用和数据处理由用户与该服务商之间的账户及政策决定。API Key 按服务商隔离，默认只保存在当前浏览器会话；只有用户主动勾选后才在本机持久保存。

3. 账户、认证与积分

Supabase Auth 处理注册、登录、邮箱验证和会话刷新。ReLens 后端处理邮箱、用户 ID、短期访问令牌、可撤销刷新令牌、积分余额、积分流水和任务状态。密码只在用户当前执行注册、登录、改密或删除账户时，于扩展页面和后台内存中短暂停留，并经 HTTPS 发送给认证服务；密码不会写入 chrome.storage、日志或 ReLens 业务数据表。

访问令牌只保存在 chrome.storage.session。只有用户主动选择“保持登录”时，刷新令牌才保存到 chrome.storage.local。退出登录会删除本机令牌。

4. 图片分析与图片生成

托管服务已启用且用户开始托管分析后，扩展会发送所选图片、补充要求、模型指令、随机请求编号和短期访问令牌。用户开始生成后，还会发送正向或负面提示词、比例、质量，以及仅在用户主动开启时发送的原图参考。ReLens Worker 验证账户、限流并执行积分扣除或失败退款，再调用届时公布的平台模型服务商。

ReLens 不把原图写入 Supabase 业务表。为支持断线恢复、结果找回、幂等计费和退款核对，托管分析完成后的结构化结果（包括中文提示词、英文提示词和负面提示词）会随任务记录加密传输并暂存在 Supabase，当前自动保留期最长为 30 天，之后由定时清理任务删除。托管生图完成后，Supabase 会保存模型服务商返回的临时签名图片 URL 和任务状态，最长约 48 小时，用于断线恢复和下载；URL 到期或清理后不再可用。

高级 BYOK 模式下，请求直接发送给用户选择并授权的服务商，不写入 ReLens 云端任务结果表。

5. 本地历史与云端留存

  • 本地设置和可选分析历史保留到用户清除、浏览器清理扩展数据或卸载扩展。分析历史保存结构化分析文本、服务商与模型、时间和固定来源类型，最多 100 条；最近 30 条可带低清缩略图，总存储上限约 4 MB。达到上限时先移除较旧缩略图，再移除较旧记录。历史不保存原图、本地文件名、网页域名或路径。
  • 为避免关闭弹窗丢失输入，扩展会把实际用于分析的图片副本（尺寸合适时可能与所选文件的图片内容相同）、低清预览、本地文件名（如有）、补充要求、细节选项和尺寸、请求编号等技术元数据暂存于 chrome.storage.session，最长 30 分钟。过期草稿不再恢复；它不写入永久历史、不跨设备同步，浏览器会话结束时由浏览器清空。只有用户主动开始分析时，任务内容才会发送给所选处理方。
  • 主动点击“大窗口查看”会创建文本阅读副本，含完整分析结果、来源标签（本地图可含本地文件名）和任务技术统计，不含图片或凭据。最多保留 5 份，创建后 30 分钟内可读取；过期副本不再读取，并在后续创建副本时清理。用户编辑的文字只留在当前编辑框用于复制，不改写阅读副本或原分析，也不会自动发送给模型。
  • 当前浏览器会话最多保留 20 条脱敏诊断，可包括请求编号、服务商、模型、接口域名、结果或错误状态、图片格式与字节数、尝试次数、耗时，以及服务商实际返回的 Token 计数；服务商未返回时不推算。诊断不含图片内容、API Key、访问或刷新令牌、本地文件名、来源网页域名或补充要求，不自动上传。用户主动复制或分享后，接收方可看到这些技术信息。
  • 原图、裁剪区域和原图参考只在当前任务所需的浏览器或后端处理阶段短暂停留，任务结束后不写入 ReLens 业务历史。
  • 托管分析原图不落入 Supabase；完成后的结构化文本结果最长保留 30 天；托管生图临时签名结果 URL 最长约保留 48 小时。任务与计费元数据（状态、费用、模型、来源类型和时间，不含原图）在账户存续期间保留，用于断线恢复、幂等、防滥用和退款核对。
  • 账户资料和积分流水在账户存续期间保留，用于登录、余额核对、幂等、防滥用和退款。
  • 删除账户申请核验完成后，ReLens 会永久删除认证账户、资料、图片地址和提示词结果，并去除仍需保留的任务、积分流水及供应商成本记录与账户身份的关联。基础设施备份和安全日志可能依各第三方的保留周期延迟清除。
  • 为防止同一邮箱在删除后重新注册并重复领取赠送积分，ReLens 会在服务存续期间保留由标准化邮箱和服务端秘密生成的 HMAC-SHA-256 指纹。该指纹不能直接还原明文邮箱，并且不包含姓名、用户 ID、图片、提示词、文件名或网页域名。账户删除审计与去标识化计费记录仅用于防滥用、财务对账和争议处理，不用于广告画像。

分析历史导出不包含低清缩略图、原图、密码、令牌或 API Key。生成结果不会自动加入分析历史。

6. 第三方处理方

  • Supabase：账户认证、用户 ID、积分、任务状态、最长保留 30 天的托管分析结构化文本结果，以及最长约保留 48 小时的托管生图临时签名结果 URL；不保存分析原图。
  • Cloudflare：托管并执行 ReLens Worker。用户主动注册、登录、分析、生成或删除账户时，请求中的邮箱、密码或令牌、图片与提示词会在 HTTPS 转发和处理期间经过 Worker 内存；ReLens 不把密码、令牌或原图写入业务数据库或应用日志。Cloudflare 还会按其服务规则处理提供服务与安全防护所需的网络请求元数据。
  • 阿里云百炼：托管服务启用并实际处理任务时使用的模型服务商，接收用户主动提交的分析或生成内容。
  • 用户选择的 API 服务商：仅在高级 BYOK 模式下接收对应请求。
  • Microsoft Edge：扩展分发、更新和商店支持入口。

各第三方按其服务条款和隐私政策处理收到的数据。ReLens 不向第三方出售用户数据，也不用于广告画像。

7. 权限与安全

  • activeTab：仅在用户操作后访问当前活动标签页。
  • contextMenus：提供右键分析图片入口。
  • scripting：按需注入扩展包内脚本，用于选图、框选和显示结果。
  • storage：保存设置、会话、可选刷新令牌或 BYOK Key、分析历史、缩略图和任务状态。
  • 可选主机权限：只在用户确认后连接当前配置的 API 或 ReLens Worker。

ReLens 不申请浏览历史、Cookie、摄像头、麦克风或地理位置权限，也不加载远程脚本。用户不应上传无权处理的个人信息、商业秘密或受限制内容。

8. 充值和支付

2.1.3 尚未开放在线充值，也不收集银行卡、支付账户或交易凭据。当前仅使用账户已有积分、发布者赠送积分或经核验的人工调整。未来接入支付前会更新本政策，明确支付服务商、交易数据、退款和保留规则。

9. 支持、访问与删除

用户可通过 Microsoft Edge 商店中 ReLens 页面列出的支持入口申请账户访问、更正或删除。申请时只需提供注册邮箱和请求内容，请勿发送密码、API Key 或访问令牌。已登录用户也可在设置页使用“删除账户与云端数据”，经当前密码再次验证后永久删除账户和可识别的云端内容；上述必要的去标识化防滥用、对账与删除审计记录仍会按第 5 节保留。

10. 政策变更

数据处理方式发生重大变化时，发布者会更新版本、生效日期和 Edge 商店披露；需要额外同意的功能不会在未告知的情况下自动开启。

本文件是可独立托管的公开政策页面源文件。实际公开地址和支持入口以 Microsoft Edge 商店详情页中的信息为准。
