隐私政策

政策更新：2026 年 10 月 4 日 · 适用版本：2.2.0

一句话说明

本版仅使用你自己的 API：所选图片直接发送至你配置并授权的服务商，不经 ReLens 托管转发。账户与托管功能退役不等于旧云端数据已删除。

自己的 API

由你授权接口，费用和数据处理按服务商规则。

本机资料

历史和资料库分开保存，可以导出或清除。

由你发起

仅主动测试或分析时发送对应内容。

1. 单一用途

ReLens 用于把用户主动选择的一张网页图片、网页框选区域或本地图片转换为详细的中文提示词、英文提示词、负面提示词和结构化 JSON。2.1.5 已移除扩展内图片生成入口；用户可自行复制提示词到 GPT 等外部工具。扩展不会自动把提示词或原图发送到这些工具，用户主动提交到外部工具的内容由其服务商按各自政策处理。扩展不会持续扫描网页、读取浏览历史或出售用户数据。

2. 仅使用自己的 API

2.2.0 仅使用用户自己的 API，不需要登录 ReLens 账户，不提供注册、登录、邮箱验证、免费托管试用或充值入口。新版扩展不向 ReLens 后端发送认证、账户、试用次数、分析或历史生图任务请求。

用户自行选择并授权 Google Gemini、OpenAI、Anthropic Claude 或 OpenAI-compatible 视觉接口；兼容服务可包括支持相应图片请求格式的阿里云百炼接口。请求直接发送至用户配置并授权的 API 服务商，不经 ReLens 托管转发，不写入 ReLens 云端任务结果表。费用、模型能力和服务商侧数据处理由用户与该服务商之间的账户及政策决定。

配置 API Key、接口地址和模型后，可执行连接测试并主动点击“启用此 API 并返回分析”。保存另一服务商的配置不会自动替换正在使用的服务商，返回分析不会自动提交图片。连接测试本身会向所选服务商发送合成测试内容，可能产生用量；真实分析也可能收费。

API Key 按服务商及接口来源隔离，默认只保存在 chrome.storage.session；只有用户主动选择记住 Key 后才在当前浏览器配置文件的 chrome.storage.local 持久保存。扩展只为当前配置的接口来源请求网站授权，变更接口来源需重新核对授权，不把旧来源的 Key 自动发往新的来源。Key 不进入分析历史、资料库或导出文件。

3. 图片分析与发送边界

只有用户主动开始分析时，任务内容才会发送给用户选择并授权的 API 服务商，包括所选图片、补充要求、模型指令和必要请求参数。扩展不会把来源网页地址、本地文件名或浏览历史作为分析来源标识发送给服务商；图片自身可含文字、个人信息或商业秘密，请在提交前确认有权处理。

图片按本地尺寸和清晰度策略准备。网页原图受跨域限制时，可能匿名重载同一图片地址，或在用户授予当前标签页截图权限后截取完整图片显示区域；仅将选定图片内容用于分析。读取失败、图片变化或完整图缩小后不够清晰时停止，不把不完整输入作为成功分析。

首次结果不满足结构或质量要求时，最多对同一张图片进行一次有界修正；这可能成为额外一次服务商调用并增加用量。可读文字同步和可选附加字段恢复可以在本地执行，不自动增加调用。核心结果通过后允许明确标注缺失的附加信息，不猜测缺失内容。

扩展不提供图片生成请求；旧生成页面仅作静态说明。复制文字、大窗口阅读、编辑和主动另存不会自动发送内容给模型。

4. 本机历史、草稿与资料库

本地设置和可选分析历史保留到用户清除、浏览器清理扩展数据或卸载扩展。分析历史保存结构化分析文本、服务商与模型、时间和固定来源类型，最多 100 条；最近 30 条可带低清缩略图，总存储上限约 4 MB。达到上限时先移除较旧缩略图，再移除较旧记录。历史不保存原图、本地文件名、网页域名或路径。

为避免关闭弹窗丢失输入，扩展会把实际用于分析的图片副本（尺寸合适时可能与所选文件的图片内容相同）、低清预览、本地文件名（如有）、补充要求、细节选项和尺寸、请求编号等技术元数据暂存于 chrome.storage.session，最长 30 分钟。过期草稿不再恢复；它不写入永久历史、不跨设备同步，浏览器会话结束时由浏览器清空。

主动点击“大窗口查看”会创建文本阅读副本，含完整分析结果、来源标签（本地图可含本地文件名）和任务技术统计，不含图片或凭据。最多保留 5 份，创建后 30 分钟内可读取；过期副本不再读取，并在后续创建副本时清理。未保存的编辑只留在当前编辑框用于复制；只有主动保存个人版本，编辑内容才会在本机持久保存。编辑不改写阅读副本或原分析，也不会自动发送给模型。

“已保存”是独立于普通分析历史的本机提示词资料库，最多 50 条，总上限 2 MiB。主动保存或收藏时会保存原分析快照；个人版本另外保存用户修改的中文或英文提示词，并标明修改语言，不覆盖原分析或自动翻译另一种语言。资料库不附带原图、缩略图、本地文件名、网页地址、凭据或接口配置；提示词正文和手动编辑内容按原文保留。资料库不自动上传、不跨设备同步，保留到用户删除、浏览器清理扩展数据或卸载扩展。达到数量或容量上限时拒绝新增保存，不自动清理已有条目。

取消收藏只移除收藏标记，保留已另存的副本。普通历史清理不影响资料库；关闭历史保存也不禁止主动另存。可在历史页的“已保存”中删除单条或清空资料库。移除旧版账户功能不会自动清除本机历史或资料库；历史云端资料与本机资料分别管理。

分析历史导出包含结构化分析文本、时间、服务商与模型和固定来源类型，不包含低清缩略图、原图、密码、令牌、API Key 或 Base URL。历史 JSON 导出不自动包含资料库；资料库由用户在历史页的“已保存”中选中条目后导出 TXT 或 Markdown（MD）。资料库导出包含所选条目的提示词文本和原文／个人版本标记，不附带图片、来源网页、接口配置或凭据。导出的正文仍可能包含图片中识别到的文字或用户自行输入的信息，请在对外分享前检查。

5. 本机会话诊断

当前浏览器会话最多保留 20 条脱敏诊断，可包括请求编号、服务商、模型、接口域名、结果或错误状态、图片格式与字节数、尝试次数、耗时，以及服务商实际返回的 Token 计数；服务商未返回时不推算。诊断不含图片内容、API Key、访问或刷新令牌、本地文件名、来源网页域名或补充要求，不自动上传。用户主动复制或分享后，接收方可看到这些技术信息。

诊断可包含受控校验代码、内置 Schema 字段路径及预期数据类型，不记录模型原始输出、失败字段的实际内容或凭据；还可包含受控超时阶段、分析总时限、最后一轮耗时及跳过补全原因，不保存模型思考内容。

6. 旧版云端资料与服务退役边界

移除扩展内账户与托管入口不等于删除云端数据。本次更新不删除旧云端账户、余额、流水或历史任务，也不执行云端数据迁移或清空。新版不使用或刷新旧账户会话、不查询旧托管任务、不消耗或展示旧试用次数。初始化只清除本机三项旧账户缓存：会话中的 relensManagedAccountSession、relensManagedAccountProfile 和本地持久化的 relensManagedAccountRefresh；不向服务器发送退出或删除请求，不删除用户自己的 API 凭据、本机历史或资料库。旧版残留本机数据不会用于新请求；本机清理不删除云端资料。

此前托管服务涉及 Supabase 认证、账户与业务记录，Cloudflare Worker 转发与网络安全元数据，以及阿里云百炼模型处理。旧政策约定：托管分析结构化文本结果最长保留 30 天；旧客户端或历史托管生图临时签名结果 URL 最长约保留 48 小时；账户资料、任务与结算元数据按原账户及结算规则保留。关闭入口不代表这些记录已经实际清除，也不改变原来的保留用途。

旧服务用于防重赠的标准化邮箱 HMAC-SHA-256 指纹、必要的去标识化任务与计费记录、删除审计按原政策的防滥用、对账和争议处理用途保留。删除旧账户的请求须单独核验处理；基础设施备份和安全日志可能依原第三方周期延迟清除。新版没有“删除账户与云端数据”按钮，也不会替用户自动发起删除。

如需访问、更正或删除旧版账户和云端资料，请通过 Microsoft Edge 商店中 ReLens 页面列出的支持入口提出申请，只提供注册邮箱和请求内容，请勿发送密码、API Key 或访问令牌。

7. 权限与第三方处理

activeTab：仅在用户操作后访问当前活动标签页；contextMenus：提供右键分析图片入口；scripting：按需注入扩展包内脚本进行选图、框选和显示结果；storage：保存本机设置、会话、可选 API Key、历史、资料库及任务状态。

可选主机权限用于用户确认后连接当前配置的 API。另有默认关闭的“跨网页保留悬浮窗”：用户主动开启并允许后，可在所有普通 HTTP(S) 网站读取和更改页面内容以显示悬浮界面；该权限不用于自动分析、批量提取网页或发送页面内容。浏览器内部页面和受保护页面不显示。

跨页结果仅暂存于当前浏览器会话，按浏览器窗口隔离，最多 8 个窗口；每个窗口保留最近一次显示的完整分析文本、固定来源类别、可选低清缩略图、语言、位置、收起及关闭状态。每份完整分析文本限制 256 KiB；24 小时未更新不再恢复，浏览器会话结束时清空，不保存原图、网页地址、文件名或凭据，也不跨设备同步。主动关闭后不会随换页自动重开。关闭跨页功能会停止自动恢复并注销动态脚本，但不会自动撤销可能与分析 API 共用的网站授权；如需撤销，可在浏览器扩展权限中管理。

网页内置顶偏好仅存本机。显示期间只观察网页结构、弹层/焦点状态和自身窗口的点击命中，不采集或上传网页正文，不自动分析或扩大网站权限；关闭浮窗或置顶后停止相关观察。

当前分析的第三方接收方是用户选择并授权的 API 服务商；其按自身服务条款、隐私政策和用户账户设置处理请求。Microsoft Edge 负责扩展分发、更新及商店支持入口。旧版云端处理方仅按第 6 节说明，不是新版分析的自动接收方。ReLens 不向第三方出售数据或用于广告画像，不申请浏览历史、Cookie、摄像头、麦克风或地理位置权限，不加载远程脚本。

8. 费用与政策变更

ReLens 不提供在线充值，不收集银行卡、支付账户或交易凭据。用户自行承担所选 API 服务商的测试与分析费用；扩展不承诺免费模型额度。

数据处理方式发生重大变化时，发布者会更新版本、生效日期和商店披露；需要额外同意的功能不会在未告知的情况下自动开启。
