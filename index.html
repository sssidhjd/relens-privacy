隐私政策

政策更新：2026 年 9 月 16 日 · 适用版本：2.1.13

一句话说明

ReLens 只在你主动选择图片并确认后分析；2.1.5 已移除扩展内生图入口，可自行复制提示词到 GPT 等外部工具。扩展不会自动向这些工具发送提示词或原图，也不会持续扫描网页、读取浏览历史或出售用户数据。默认托管功能会把完成分析所需的数据发送给 ReLens 后端和明确列出的模型服务商。

本机历史

可以关闭、导出或清空。不保存原图；最多 30 张低清预览。

托管结果

分析文本最多 30 天；旧客户端或历史生图结果链接约 48 小时，用于找回结果和结算。

由你发起

分析需要发送图片与文字。关闭本机历史不代表停止云端处理。

以上是便于阅读的摘要。完整的数据处理范围、保留规则和第三方说明，请查看下方条款。

2.1.13 托管分析规则：每个已验证邮箱账户累计最多 5 次成功托管分析，历史成功次数算入；处理中或待核对任务暂占次数，确认失败并退款后归还。次数沿用既有任务/结算元数据和邮箱 HMAC 核对，不增加原图留存，不清空旧余额、流水或本地历史。不接受新的托管生图请求，历史查询和结算保留。

2.1.6 的本机脱敏诊断还可包含受控校验代码、内置 Schema 字段路径及预期数据类型。这些信息仅来自程序认可的结构，不记录模型原始输出、失败字段的实际内容或凭据；仍沿用最多 20 条、当前浏览器会话、不自动上传的规则。

2.1.7 增加受控超时阶段、分析总时限、最后一轮耗时及跳过补全原因，仅保存程序认可的阶段名称与数值，不保存模型思考内容，也不增加诊断留存或上传。

2.1.8 可在本地将模型已返回的可读文字同步到中英文提示词，清除空项，并把明确的未辨认占位项转为警告；这个处理本身不调用 API，不增加上传对象、历史或诊断留存，不改写旧历史。

2.1.9 调整双语提示词的模块组织，并提供独立的网页内置顶开关。置顶偏好仅存于当前浏览器本地；显示期间只观察网页结构、弹层/焦点状态和自身窗口的点击命中，不采集网页正文，不上传这些状态，不自动分析或扩大网站权限。关闭浮窗或置顶后停止相关观察；既有跨页授权、历史和云端留存规则不变。

本地临时数据补充说明

为恢复未提交或待重试的输入，浏览器会话可暂存实际用于分析的图片副本、低清预览、本地文件名（如有）、补充要求、细节选项和任务技术元数据，最长 30 分钟。过期草稿不再恢复；它不进入永久历史、不跨设备同步，浏览器会话结束时由浏览器清空。只有你主动开始分析时，任务内容才会发送给所选处理方。

主动打开的大窗口最多保留 5 份文本阅读副本，包含完整分析结果、来源标签（本地图可含本地文件名）和任务技术统计，不含图片或凭据；创建后 30 分钟内可读取，过期后不再读取并在后续创建副本时清理。编辑的文字只留在当前编辑框用于复制，不改写阅读副本或原分析，也不会自动调用模型。

当前浏览器会话最多保存 20 条脱敏诊断，可包括请求编号、服务商、模型、接口域名、状态、图片格式与字节数、尝试次数、耗时和服务商实际返回的 Token 计数；服务商未返回时不推算。诊断不含图片内容、API Key、访问或刷新令牌、本地文件名、来源网页域名或补充要求，也不自动上传；只有你主动复制、分享后，接收方才会看到这些技术信息。

1. 单一用途

ReLens 把用户主动选择的一张网页图片、网页框选区域或本地图片转换为中文提示词、英文提示词、负面提示词和结构化 JSON。2.1.5 已移除扩展内图片生成入口；用户可自行复制提示词到 GPT 等外部工具生成图片，扩展不会自动把提示词或原图发送到这些工具。用户主动提交到外部工具的内容由其服务商按各自政策处理。

2. 两种使用方式

ReLens 托管模式（默认）：托管分析要求登录并验证邮箱，每个账户累计最多免费成功分析 5 次，无需模型 API Key。历史成功托管分析计入；reserved / processing / review_required 等处理中或待核对任务暂占次数，确认失败并退款后归还，同一成功任务及自动补全只计 1 次。未知状态显示待核对，不按余额推算。扩展把完成图片分析所需的数据发送至 ReLens 后端，再由后端调用平台模型。

次数不会每日、重新登录或重装扩展后重置；同一邮箱删除账户后重新注册不重赠。达到上限或当前无可用试用时，可配置自己的 API 继续使用；旧余额或新增积分不能绕过 5 次上限。

使用自己的 API（高级）：用户自行选择并授权 Google Gemini、OpenAI、Anthropic Claude、阿里云百炼或 OpenAI-compatible 服务，无需登录 ReLens。请求直接发送至相应接口，费用和数据处理由用户与该服务商之间的账户及政策决定。打开模型页或保存 API Key 不会自动切换分析方式，需在常用设置主动选择自己的 API 并保存。

3. 账户、认证与试用计次

Supabase Auth 处理注册、登录、邮箱验证和会话刷新。ReLens 后端处理邮箱、用户 ID、短期访问令牌、可撤销刷新令牌、原有积分余额与流水、任务状态，以及据此核对的试用已用、暂占和剩余次数。次数由服务端校验，清理本机数据不能重置；本次调整不清空旧余额或流水。密码只在用户当前执行注册、登录、改密或删除账户时，于扩展页面和后台内存中短暂停留，并经 HTTPS 发送给认证服务；密码不会写入浏览器存储、日志或 ReLens 业务数据表。

访问令牌只保存在浏览器会话；只有用户主动选择“保持登录”时，刷新令牌才保存在当前浏览器配置文件。退出登录会删除本机令牌。

4. 图片分析与历史生图任务

用户开始托管分析后，扩展会发送所选图片、补充要求、模型指令、随机请求编号和短期访问令牌。ReLens Worker 验证账户、核对试用次数和并发占用、限流，并沿用既有结算及失败退款核对，再调用当前公布的平台模型服务商。结果未知或待核对时不会提前归还次数，确认失败并退款后归还，成功后计入累计次数。

旧客户端过去主动发起的生图任务可能发送正向/负面提示词、比例、质量，以及仅在用户主动开启时发送的原图参考。2.1.13 后台拒绝新托管生图 POST 请求，不再为该入口创建模型任务；已有任务查询与结算继续兼容。下述生图留存规则仅说明既有云端任务的处理，关闭新建入口不会删除历史任务、数据库记录或已保存凭据。

ReLens 不把原图写入 Supabase 业务表。为支持断线恢复、结果找回、幂等计费和退款核对，托管分析完成后的结构化结果（包括中文、英文和负面提示词）会暂存在 Supabase，当前最长保留 30 天；旧客户端托管生图任务完成后，Supabase 会保存模型服务商返回的临时签名图片 URL 和任务状态，最长约 48 小时，用于断线恢复和下载。高级 BYOK 模式下，请求直接发送给用户选择并授权的服务商，不写入 ReLens 云端任务结果表；API Key 按服务商隔离，默认只保存在当前浏览器会话，只有用户主动勾选后才在本机持久保存。

5. 本地历史与云端留存

  • 本地设置和可选分析历史保留到用户清除、浏览器清理扩展数据或卸载扩展。分析历史保存结构化分析文本、服务商与模型、时间和固定来源类型，最多 100 条；最近 30 条可带低清缩略图，总存储上限约 4 MB。达到上限时先移除较旧缩略图，再移除较旧记录。历史不保存原图、本地文件名、网页域名或路径。
  • 为恢复未提交或待重试的输入，浏览器会话可暂存实际用于分析的图片副本、低清预览、本地文件名（如有）、补充要求、细节选项和任务技术元数据，最长 30 分钟。过期草稿不再恢复，也不写入永久历史或跨设备同步。
  • 大窗口文本阅读副本最多保留 5 份，包含来源标签（本地图可含本地文件名），创建后 30 分钟内可读取；当前浏览器会话最多保留 20 条不含图片或凭据的脱敏诊断。这两类数据都不自动上传。
  • 原图、裁剪区域和旧客户端生图任务的原图参考只在当前任务所需的浏览器或后端处理阶段短暂停留，任务结束后不写入 ReLens 业务历史。
  • 托管分析结构化文本结果最长保留 30 天；旧客户端或历史托管生图临时签名结果 URL 最长约保留 48 小时。任务与计费元数据、账户资料和积分流水在账户存续期间保留。
  • 删除账户后会永久删除认证账户、资料、图片地址和提示词结果；仍需保留的任务、积分流水和供应商成本记录会解除与账户身份的关联。
  • 为防止重复领取赠送积分，服务存续期间会保留由标准化邮箱和服务端秘密生成、不能直接还原明文邮箱的 HMAC-SHA-256 指纹；该指纹和删除审计、去标识化计费记录不含用户 ID、图片、提示词、文件名或网页域名，仅用于防滥用、对账和争议处理。

分析历史导出包含结构化分析文本、时间、服务商与模型和固定来源类型，不包含低清缩略图、原图、密码、令牌、API Key 或 Base URL。历史生图结果不会自动加入分析历史。

2.1.13 累计试用依据上述账户存续期间的任务与结算元数据核对，不依赖保存原图；提示词结果到期或删除本机历史不会重置已成功使用的次数。防重赠沿用标准化邮箱的 HMAC-SHA-256 指纹，同一邮箱删除后重新注册不会获得新一轮 5 次免费试用。该指纹及必要的去标识化记录沿用上述服务存续期间的防滥用、对账和争议处理用途，不增加原图或提示词留存。

6. 第三方处理方

  • Supabase：账户认证、用户 ID、原有积分和任务状态、累计试用核对所需的任务/结算元数据、既有邮箱 HMAC 防滥用指纹、最长保留 30 天的托管分析结构化文本结果，以及旧客户端或历史托管生图任务中最长约保留 48 小时的临时签名结果 URL；不保存分析原图。
  • Cloudflare：托管并执行 ReLens Worker。用户主动注册、登录、分析或删除账户，以及旧客户端过去主动发起生图任务时，邮箱、密码或令牌、图片与提示词会在 HTTPS 转发和处理期间经过 Worker 内存；ReLens 不把密码、令牌或原图写入业务数据库或应用日志。Cloudflare 还会处理服务和安全防护所需的网络请求元数据。
  • 阿里云百炼：当前托管模型能力；接收用户主动提交的分析内容，以及旧客户端过去主动提交的生图任务内容。
  • 用户选择的 API 服务商：仅在高级 BYOK 模式下接收对应请求。
  • Microsoft Edge：扩展分发、更新和商店支持入口。

各第三方按其服务条款和隐私政策处理收到的数据。ReLens 不向第三方出售用户数据，也不用于广告画像。

7. 权限与安全

  • activeTab：用户操作后访问当前标签页。
  • contextMenus：提供右键分析入口。
  • scripting：按需注入扩展包内脚本进行选图、框选和显示结果。
  • storage：保存设置、会话、可选刷新令牌/BYOK Key、历史和任务状态。
  • 可选主机权限：用户确认后连接当前配置的 API 或 ReLens Worker；另可主动授权所有普通 HTTP(S) 网站，以跨网页显示悬浮窗。

扩展不申请浏览历史、Cookie、摄像头、麦克风或地理位置权限，也不加载远程脚本。

“跨网页保留悬浮窗”默认关闭，只有主动开启并接受浏览器网站权限后才启用。权限允许读取和更改网站内容以显示界面，不用于自动分析、批量提取或发送页面内容。仅在浏览器会话中按窗口保留最近一次分析文本、固定来源类别、可选低清缩略图、语言、位置和收起/关闭状态：最多 8 个窗口，每份分析文本不超过 256 KiB，24 小时未更新不再恢复，会话结束清空。不保存原图、网页地址、文件名或凭据，不跨设备同步。

主动关闭后不会随换页重弹；重新主动分析或显示结果可再次打开。关闭跨页功能会停止自动恢复并注销动态脚本，不会自动撤销可能与分析 API 共用的网站权限。需要撤销时，可在浏览器扩展权限中管理。浏览器内部或受保护页面无法显示网页浮窗。

8. 充值和支付

2.1.13 不提供在线充值，也不收集银行卡、支付账户或交易凭据。免费托管试用累计最多 5 次，不能通过充值或增加旧积分绕过上限；试用不可用时可主动配置自己的 API，按该服务商规则付费。旧余额与流水只为历史兼容和结算保留，不是付费解锁功能。更新不会清空旧余额。未来如引入其他支付功能，会先更新政策并明确支付服务商、交易数据、退款和保留规则。

9. 支持、访问与删除

用户可通过 Microsoft Edge 商店中 ReLens 页面列出的支持入口申请账户访问、更正或删除。申请时只需提供注册邮箱和请求内容，请勿发送密码、API Key 或访问令牌。已登录用户也可在设置页使用“删除账户与云端数据”，经当前密码再次验证后永久删除账户和关联活动业务数据。

10. 政策变更

数据处理方式发生重大变化时，发布者会更新版本、生效日期和 Edge 商店披露；需要额外同意的功能不会在未告知的情况下自动开启。
